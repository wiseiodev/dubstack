# .agents Contributor Notes

This folder holds guidance aimed at coding agents and contributors collaborating with coding agents.

## What To Put Here

- `skills/`: task-oriented skills with runnable workflows and references.
- `styleguide.md`: project-wide coding and testing conventions for day-to-day edits.
- `patterns/`: focused implementation patterns used across commands and libraries.

## Suggested Future Additions

- `patterns/release-workflow.md`: versioning and release checklist conventions.
- `patterns/performance.md`: profiling and performance regression guardrails for CLI flows.
- `patterns/backward-compatibility.md`: guidance for preserving command/flag behavior contracts.

Current pattern docs:

- `patterns/command-changes.md`
- `patterns/testing.md`
- `patterns/error-messages.md`
- `patterns/git-safety.md`

Keep these docs short, practical, and example-driven so both humans and agents can apply them quickly.
